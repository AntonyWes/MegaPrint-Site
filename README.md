# Копицентр «МегаПринт» — одностраничник

Статический лендинг для копицентра «МегаПринт» в Витебске (пр-т Победы, 7/2).
Без сборки и зависимостей: чистые HTML, CSS и JS.

## Запуск

```bash
python3 -m http.server 4173
```

Открыть `http://localhost:4173`.

Можно открыть `index.html` напрямую, но для корректной работы шрифтов, карты и `manifest` лучше через локальный сервер.

## Деплой

- Репозиторий: https://github.com/AntonyWes/MegaPrint-Site
- GitHub Pages: https://antonywes.github.io/MegaPrint-Site/

Pages настроен на ветку `main` и корень репозитория. После правок достаточно:

```bash

git push
```

GitHub Pages пересоберёт сайт автоматически. `.nojekyll` уже лежит в корне.

## Что внутри

- `index.html` — разметка, SEO-мета, JSON-LD, формы и диалоги.
- `styles.css` — дизайн, адаптив, анимации, печатная версия.
- `script.js` — мобильное меню, модалка заявки, валидация, статус «сейчас открыто», FAQ, лайтбокс галереи.
- `assets/` — логотип (вектор + оригинал), шрифты, фото работ, фавиконки, OG-картинка.
- `manifest.webmanifest` — иконки и цвета для установки на домашний экран.

## Логотип

Знак «М» перерисован в SVG по оригинальному логотипу, чтобы он оставался резким на любом экране. Оригинальный растровый логотип лежит в `assets/logo-original.jpg`. Если есть исходник в AI/SVG — лучше заменить вектор на официальный.

## Форма заявки

Бэкенда нет. Форма:

1. валидируется нативно (обязательные поля, согласие);
2. собирает письмо и открывает почтовую программу с готовым текстом на `m_odin@inbox.ru`;
3. показывает экран «Заявка сформирована» с кнопками Telegram, Viber и копированием текста на случай, если почтовый клиент не настроен.

Если нужна настоящая отправка без почтового клиента — подключить Telegram-бота, Formspree, Getform или собственный endpoint. Скажи, куда отправлять — переделаю.

## Перед публикацией

1. **Домен и OG-картинка.** В `index.html` заменить относительные `og:image` и `twitter:image` на абсолютные URL после деплоя, добавить `og:url` и canonical.
2. **Прайс.** Цены на сайте — ориентиры из публичных карточек и уточнение по работе менеджера, не публичная оферта. Лучше прислать актуальный прайс и обновить блок «Прайс».
3. **Фото работ.** Сейчас стоят фото из публичных карточек компании. Для продакшена лучше заменить на свежие исходники в хорошем разрешении и проверить права на использование.
4. **Юрлицо, УНП, часы.** Подтвердить актуальность.
5. **Политика конфиденциальности.** Сейчас это короткая заглушка в диалоге. Для полноценного сайта нужен отдельный документ, если он требуется по законодательству.

## Проверки

- HTML проходит `html-validate` (без ошибок).
- JS проходит `node --check`.
- Axe-core (WCAG 2.1 A/AA) не находит нарушений на странице, в модалке, диалоге privacy, лайтбоксе и мобильном меню.
- Проверено в Chrome на ширинах 320, 360, 375, 390, 768, 1024, 1280, 1440, 1920 px.
- Нет горизонтального скролла, битых изображений и ошибок в консоли.
- Учтён `prefers-reduced-motion`, есть skip-link, focus-visible, `inert` для закрытого мобильного меню и клавиатурная навигация.
